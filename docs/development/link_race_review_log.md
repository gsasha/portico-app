## Corrections recorded

- Earlier claim in the PR/worker report: "no race while a stream is open, so a link loss during a call keeps the existing grace logic". Wrong in effect: it also removed the 6 s mobile deadline (A3/B3). Corrected above.
- Earlier claim: "a candidate does not put the tailnet node to sleep". Wrong: it cancels the pending warm-hold timer and can wake the node (A7/B4).
- Earlier claim: "A command not yet sent goes out on the primary". Wrong for the race window: it can be granted on a link the swap then discards (A1).

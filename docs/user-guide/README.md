This guide explains each part of the app as you meet it. Pages are short and independent; read the ones you need.

| Page | Read it when |
| :--- | :--- |
| [Home: cameras and buttons](home-screen.md) | You want to know what the main screen shows, how tiles resize and zoom, what the status dot means |
| [Talk to the door, call buttons and house calls](talk-and-house-calls.md) | You use Talk, call buttons or ring other phones in the house |
| [Answering a door call](answering-a-door-call.md) | A call is ringing, or a call failed |
| [The ring and in-call screens](ring-and-in-call-screens.md) | You want to know what appears during a call |
| [Live video](live-video.md) | Camera tiles play live video, at home or away |
| [Notifications, the ring and Settings status](notifications-and-settings-status.md) | The phone does not ring, or rings quietly; Do Not Disturb |
| [Pause](pause.md) | You want the app silent for a while |
| [Stay connected](stay-connected.md) | You want rings to arrive without opening the app |
| [Roaming block and the data meter](roaming-and-data-meter.md) | You travel, or care about mobile data |
| [When the phone cannot reach Home Assistant](when-the-phone-cannot-reach-ha.md) | The status is red, or push cannot register |

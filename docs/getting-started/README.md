# Getting started

Three short pages take you from nothing to your first call. Read them in order.

1. [Requirements and install](requirements-and-install.md): what you need on the phone and the server, and how to install the APK.
2. [Enrolling a phone](enrolling-a-phone.md): scan the QR from Home Assistant (or paste its text) and check Settings.
3. [Your first call](first-call.md): what a ring looks like, how to answer, and what to check if nothing rings.

**Prefer a guided setup?** Install [portico-ha](https://github.com/gsasha/portico-ha) using its [AI setup prompt](https://github.com/gsasha/portico-ha/blob/main/docs/getting-started/ai-setup-prompt.md). It guides you, step by step, through the server and through setting up this app (install the APK from this repository's Releases, enrol by QR). Paste this to an AI assistant: "Read https://raw.githubusercontent.com/gsasha/portico-ha/main/docs/getting-started/ai-setup-prompt.md and follow it to help me install Portico and its Android app."
